How to switch environments

  • ng serve — Development (default)
  • ng serve --configuration=test — TEST
  • ng serve --configuration=uat — UAT
  • ng serve --configuration=production — PROD
  • ng build --configuration=test — Build for TEST
  • ng build --configuration=uat — Build for UAT
  • ng build — Build for PROD (default)
